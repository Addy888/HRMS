fix: Remove system roles from employee designation dropdown

ISSUE:
"Super Admin" was appearing in the Employee Creation form's Designation dropdown.
This is incorrect because "Super Admin" is an authentication role, not a job title.

ROOT CAUSE:
setup-initial-organization.ts was mistakenly creating "Super Admin" as a 
Designation entry instead of keeping it only as a Role entry.

CHANGES:
1. Fixed setup-initial-organization.ts
   - Removed code that created "Super Admin" designation
   - Now creates proper employee designations (Manager, Team Leader, etc.)

2. Enhanced designations.service.ts
   - Added filtering to exclude system role names from designation list
   - Blocks: SUPER_ADMIN, HR_ADMIN, HR_USER, EMPLOYEE, ADMIN variants

3. Created utility scripts:
   - cleanup-system-role-designations.ts - Removes system roles from DB
   - seed-employee-designations.ts - Seeds 20 proper designations
   - test-designation-api.ts - Validates the fix

RESULT:
✅ Employee designation dropdown now shows ONLY employee job titles
✅ System roles (Super Admin, HR_ADMIN, etc.) no longer appear
✅ Backend filtering prevents future mistakes
✅ Database cleaned of invalid entries
✅ 20 proper employee designations added
✅ Organization isolation maintained
✅ All tests passing
