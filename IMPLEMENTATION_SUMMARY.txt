16. LIMITATIONS & KNOWN ISSUES
================================================================================

Current Limitations:
- File size: Max 5MB (~50,000 rows)
- Session timeout: 30 minutes for preview
- File format: Excel only (.xlsx, .xls) - no CSV
- One import per HR user at a time

Not Implemented (Intentional):
- Bulk delete (production safety)
- CSV import (Excel only)
- Scheduled imports (manual only)
- Direct biometric integration (Excel required)

Known Issues:
- Prisma generate permission warning (not critical)
- Socket.IO may not work if WebSocket blocked (has fallback)
