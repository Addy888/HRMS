## 📝 EMPLOYEE ID SYSTEM DETAILS

### Format Specification
```
FCS0151 = FCS + 0151
├─ FCS: Fixed prefix
└─ 0151: 4-digit sequence starting from 151
```

### Examples
```
First employee:  FCS0151
Second employee: FCS0152
Third employee:  FCS0153
...
10th employee:   FCS0160
...
100th employee:  FCS0250
...
1000th employee: FCS1150
```

### Thread Safety
```typescript
// Query finds last ID
SELECT employeeId FROM Employee 
WHERE organizationId = ? 
AND employeeId LIKE 'FCS%' 
AND employeeId NOT LIKE '%-' 
ORDER BY employeeId DESC 
LIMIT 1;

// Extract number, increment, format
lastId = "FCS0151"
number = 151
nextNumber = 152
newId = "FCS0152"
```
