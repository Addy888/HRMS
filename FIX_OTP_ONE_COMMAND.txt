═══════════════════════════════════════════════════════════

STEP 1: Stop Backend
────────────────────────────────────────────────────────────
In your backend terminal, press:

    Ctrl + C


STEP 2: Apply Migration
────────────────────────────────────────────────────────────
Copy and paste:

    cd backend && npx prisma migrate deploy

Press Enter.

Expected output:
    Applying migration `20260808102317_add_otp_verification`
    Migration applied successfully


STEP 3: Generate Prisma Client
────────────────────────────────────────────────────────────
Copy and paste:

    npx prisma generate

Press Enter.

Expected output:
    ✔ Generated Prisma Client


STEP 4: Start Backend
────────────────────────────────────────────────────────────
Copy and paste:

    npm run start:dev

Press Enter.

Expected output:
    ⚡ Server running on port 4000


STEP 5: Test OTP Login
────────────────────────────────────────────────────────────
1. Open: http://localhost:3000/login/employee
2. Enter employee email/password
3. OTP should be generated
4. No error about "table does not exist"
